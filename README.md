# 🚀 CareerSprint OS — Менторский Кокпит Fullstack & AI

Интерактивная карьерная операционная система, пошаговый спринт-план, HR-стратегия, CRM воронка вакансий и тренажер собеседований для перехода на удаленную Fullstack разработку (NestJS / Next.js 15 / React / TypeScript + AI Integrations).

## 🌟 Ключевые возможности

1. **Спринт-План (Roadmap на 6 Спринтов / 12 Недель):**
   - Интерактивный трекинг перехода от первого Part-time дохода (50 000 – 120 000 ₽/мес) до устойчивой Full-time удаленки (220 000 – 280 000+ ₽/мес).
   - Чек-листы задач, дедлайны, артефакты, фильтры и сохранение прогресса в `localStorage`.

2. **Аудит Резюме 2.0 & GitHub Showcase:**
   - Детальный разбор слабых мест резюме с готовыми заменами по стандарту автономного Product Fullstack инженера.
   - Аудит репозиториев (`corporate-transport`, `docbrain`, `scan-agent`, `support-ticketing-system`).
   - Скрипты ответа на каверзные вопросы HR (возраст 41 год, переход, частичная занятость).

3. **Генератор Питчей и Холодных Писем:**
   - Персонализированные шаблоны для Telegram-аутрича к СТО и фаундерам студий, B2B продаж RAG-систем и сопроводительных писем на HH.ru / Хабр Карьере.
   - Каталог проверенных Telegram-каналов с прямыми контактами нанимателей.

4. **CRM Воронка Вакансий (Job Kanban):**
   - Управление циклом отклика: *В бэклоге → Отклик отправлен → Скрининг HR → Техническое интервью → Оффер*.

5. **Тренажер Техинтервью (Hard Skills Flashcards):**
   - База каверзных вопросов по Event Loop, жизненному циклу NestJS, React 19 / Server Actions в Next.js 15, индексам PostgreSQL, pgvector HNSW vs IVFFlat и System Design.

6. **Финансовый Калькулятор Перехода:**
   - Расчет часовой ставки, чистой прибыли после налога самозанятого (6% НПД), подушки безопасности и индекса готовности к безопасному переходу на Full-time.

## 🛠 Технологический стек

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Motion, Lucide React
- **Bundler & Tooling:** Vite 8, ES2022
- **CI/CD:** GitHub Actions (автоматический деплой на GitHub Pages)

## 💻 Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/DNikulshinWork/career-sprint-os.git
cd career-sprint-os

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production билда
npm run build
```
